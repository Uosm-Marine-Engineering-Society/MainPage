Publish live updates

Complete this once. Afterwards, authorised users can update the live site from this dashboard.

1. Create a Supabase project. 2. Run schema.sql in the SQL editor. 3. Create an Auth user. 4. Add that user's ID to the admins table. 5. Paste the project URL and publishable key into supabase-config.js. 6. Upload this folder to your web host.
Use only the public publishable or anon key in the browser. Never use a service-role key in this website.

Full setup steps are included in README.md. Local preview mode remains available for testing and content preparation before the database is connected.
